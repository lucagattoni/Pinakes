# Courier requirements

A courier accompanies any object whose loss would be unrecoverable, and has authority to stop the
movement. A courier who cannot say no is a passenger.

The courier witnesses packing and unpacking at both ends and signs the condition report there and
then. Signing later, from notes, is the point at which the record stops being evidence.

Couriers are named in the loan agreement before the object moves, and a substitution is agreed in
writing.
