# Emergency salvage

Salvage priorities are marked on the store plan itself, not held in a separate list. A list that has
to be fetched is a list that will not be used.

Wet organic material is frozen; wet metal is dried immediately. The two instructions contradict each
other on purpose, and the plan says which applies to which store bay.

The museum and the Institute hold each other's salvage plans and each other's out-of-hours numbers.
Neither has enough freezer capacity alone.
