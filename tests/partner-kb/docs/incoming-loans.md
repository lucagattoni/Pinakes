# Incoming loans

Borrowed objects are held apart from the permanent collection and are never given an accession
number. The register records ownership, and a borrowed object has an owner elsewhere.

A facilities report is supplied to the lender before the request is made, not after it is refused.
Lenders assess the building, not the exhibition.

Borrowed material leaves on the agreed date. An overstayed loan is the commonest way an institution
acquires something it cannot account for.
