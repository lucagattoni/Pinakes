# Outgoing loans

A request to borrow is assessed on the object's condition first and the borrower's building second.
An object too fragile to travel does not become fit to travel because the venue is excellent.

The museum supplies a condition report, a mount specification and a courier where the object
warrants one. Sending an object without a mount specification delegates a conservation decision to
whoever unpacks it.

Loans are refused in writing, with the reason. A refusal without a reason is read as an opinion of
the borrower.
