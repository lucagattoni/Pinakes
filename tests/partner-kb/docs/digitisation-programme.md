# Digitisation programme

The joint programme photographs museum objects and Institute records in one workflow, so that an
object and the paperwork documenting it are captured to the same standard in the same season.

Capture follows the Institute's standards, which are stricter than the museum's own and already
written down. Two standards for one programme produces a collection that has to be re-shot.

Selection is by research demand, not by photogenic quality. A programme that digitises what looks
best digitises what is already known.
