# Object numbering

Numbers are of the form `YYYY.NN.pp` — year of accession, sequence within the year, part within the
object. Parts are numbered even when there is only one, so that a lid found later does not force the
whole object to be renumbered.

Numbers are never reused. A gap in the sequence is cheaper than an ambiguity, and a reused number
silently merges two object histories.
